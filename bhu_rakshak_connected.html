Connect your Python/Flask XGBoost Backend

This dashboard is connected directly to the Flask API running locally. Click a location on the map to send latitude and longitude to the trained XGBoost model.

1. Flask XGBoost endpoint

Running at http://127.0.0.1:5000/predict

POST /predict
{
  "latitude": 25.5788,
  "longitude": 91.8933
}

Response:
{
  "probability": 82.41,
  "risk": "Very High",
  "elevation": 1520.4,
  "slope": 28.7,
  "rainfall": 1980.2,
  "land_cover": 10,
  "clay": 27.4,
  "river_distance": 0.42
}

2. Map → AI workflow

Click a point and the browser sends its coordinates to Flask.

map.on("click", async (e) => {
  const response = await fetch(
    "http://127.0.0.1:5000/predict",
    {
      method: "POST",
      headers: { "Content-Type": "application/json" },
      body: JSON.stringify({
        latitude: e.latlng.lat,
        longitude: e.latlng.lng
      })
    }
  );
});
